# 入馆须知

**神人志**是一座神人档案馆。本馆只做记录，不做治疗。

## 收录标准

满足以下任意一条，方可入册：

1. 言行举止令周围正常人产生「他是怎么活到现在的」之疑惑；
2. 拥有可复现的、稳定的、自成体系的神人逻辑；
3. 有至少一张可归档的图像证物。

## 档案规范

- 档案文件放在 `docs/archives/`，命名格式 `编号-代号.md`；
- 图像证物统一放在 `docs/public/images/`，命名格式 `编号-序号-说明.png`；
- 在 Markdown 中一律用绝对路径引用图片：`![说明](/images/编号-序号-说明.png)`，本地开发（`/`）与线上构建产物中都可访问；
- 每份档案建议包含：**基本信息、症状描述、典型事迹、证物图片、确诊结论** 五个部分（见 [档案模板](/archives/template)）；
- 建档后请到 [档案索引](/archives/) 登记，并在 `.vitepress/config.ts` 侧边栏补一条链接。

写好的档案直接提 PR 即可，不必强行走完上面全部流程。
