# 入馆须知

**神人志**是一座神经病档案馆。本馆只做记录，不做治疗。

## 收录标准

满足以下任意一条，方可入册：

1. 言行举止令周围正常人产生「他是怎么活到现在的」之疑惑；
2. 拥有可复现的、稳定的、自成体系的神人逻辑；
3. 有至少一张可归档的图像证物。

## 档案规范

- 档案文件位于 [archives](/archives/)，命名格式：`编号-代号.md`，如 `001-night-singer.md`；
- 图像证物统一存放于 `docs/public/images/`，命名格式：`编号-序号-说明.png`，如 `001-01-stage.png`；
- 在 Markdown 中一律使用绝对路径引用：`![说明](/images/001-01-stage.png)`，开发（`/`）与构建产物中均可用；
- 每份档案必须包含：**基本信息、症状描述、典型事迹、证物图片、确诊结论** 五个部分。

## 免责声明

本馆内容纯属虚构，如有雷同，建议就医。
