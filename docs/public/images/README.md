# 神人志 · 图片证物库

本目录是档案馆的**独立图片文件夹**，站点构建后映射到网站根路径 `/images/`。

## 存放规则

- 命名：`编号-序号-说明.png`，例：`001-01-lamp-stage.png`
- 一份档案的图片按序号递增，说明用英文或拼音（避免 URL 转义问题）
- 格式建议：`.png` / `.jpg` / `.webp`，单张控制在 500 KB 内

## 在 Markdown 中引用

始终用**绝对路径**（本目录即根路径），开发预览和构建产物都可用：

```md
![001号现场取证](/images/001-01-lamp-stage.png)
```

需要控制尺寸时用 HTML 标签：

```html
<img src="/images/001-01-lamp-stage.png" alt="现场取证" width="320" />
```

不要用相对路径 `../public/images/...` 或 `./images/...`，跨目录引用容易失效。
