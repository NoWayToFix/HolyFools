# 神人志 · 图片证物库

本目录是档案馆的**独立图片文件夹**，构建后映射到网站根路径 `/images/`。

## 存放规则

- 命名：`编号-序号-说明.png`，例：`002-01-patrol.png`
- 一份档案的图片按序号递增；说明部分用英文或拼音，避免 URL 转义问题
- 格式建议 `.png` / `.jpg` / `.webp`，单张控制在 500 KB 内

## 在 Markdown 中引用

始终用**绝对路径**（本目录即网站根路径），本地预览和线上都可用：

```md
![现场取证](/images/002-01-patrol.png)
```

需要控制尺寸时改用 HTML 标签：

```html
<img src="/images/002-01-patrol.png" alt="现场取证" width="320" />
```

注意：不要把还没放进来的图片写成 Markdown 图片语法，VitePress 构建时会把 `![...](/images/xxx.png)` 当真去解析，文件不存在就报 dead link 并中断构建。写规范说明时请放进代码块（就像本页这样）。
